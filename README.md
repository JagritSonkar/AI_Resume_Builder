# 🤖 AI Resume Builder

A modern, professional, and responsive AI-powered resume builder built with React. Create ATS-friendly resumes in minutes with the power of AI.

## ✨ Features

- **AI Resume Writing**: Advanced AI helps write professional resume content
- **ATS Friendly**: All templates optimized for Applicant Tracking Systems
- **Custom Templates**: 4 beautiful, professionally designed templates
- **Instant PDF Download**: Download your resume as high-quality PDF
- **Smart Suggestions**: Intelligent suggestions for skills and experience
- **Dark/Light Mode**: Toggle between dark and light themes
- **Fully Responsive**: Works perfectly on mobile, tablet, and desktop
- **Live Preview**: See your resume update in real-time
- **Modern UI/UX**: Clean, minimal design with smooth animations

## 🚀 Getting Started

### Prerequisites

- Node.js (v14 or higher)
- npm or yarn

### Installation

1. **Install dependencies**
   ```bash
   npm install
   ```

2. **Start the development server**
   ```bash
   npm start
   ```

3. **Open your browser**
   Navigate to `http://localhost:3000`

### Build for Production

```bash
npm run build
```

## 📝 How to Use

1. **Fill Your Details**: Enter your personal information, skills, experience, education, and projects
2. **Generate with AI**: Click "Generate Resume with AI" to enhance your content
3. **Choose Template**: Select from 4 professional templates
4. **Download PDF**: Click "Download PDF" to save your resume

## 🌙 Dark Mode
